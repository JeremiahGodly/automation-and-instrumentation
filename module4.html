Part 1 · Syllabus Theory (Simplified & Clear)

4.1 Introduction & Organisation of a PLC

💡 In Simple Terms: Before PLCs, factories used giant control panels with thousands of mechanical relays wired together like a massive spiderweb. If an engineer wanted to change the machine sequence, technicians spent days rewiring hundreds of cables! A PLC (Programmable Logic Controller) replaces all those hardwired relays with a rugged, microprocessor-based computer. To change the sequence, you simply update the software ladder diagram—zero rewiring needed!

The Three Internal Buses

  • Address Bus: Carries binary address signals from CPU to specify which memory location or I/O channel is being accessed.
  • Data Bus: Bi-directional data lines (8, 16, or 32 bits) carrying measurement data and instruction words.
  • Control Bus: Carries synchronization timing signals (Read/Write pulses, Clock, Interrupts).

The PLC Scan Cycle

Unlike personal computers running hundreds of background apps, a PLC executes a continuous, deterministic 4-step loop:

  1. Input Scan: Reads all physical input terminal states and copies them into the Input Image Table in RAM.
  2. Program Scan: Executes the user ladder program rung-by-rung from top to bottom, evaluating logic using the image table.
  3. Output Scan: Copies the resulting Output Image Table bits to energise physical output terminals.
  4. Housekeeping & Diagnostics: Performs self-diagnostics, communications with programming PC/HMI, and resets the watchdog timer.

Total scan time is typically $1\text{ to }20\text{ milliseconds}$.

4.2 Hardware Details: CPU, I/O Modules & Power Supply

1. Central Processing Unit (CPU)

The "brain" containing the microprocessor, math ALU, registers, and memory. Performs program fetching, execution, mathematical calculations, timers/counters, and communications. Memory includes:

  • ROM (Read-Only Memory): Stores permanent operating system (executive firmware) burned in by manufacturer.
  • RAM (Random Access Memory): Fast memory holding user ladder logic, timer accumulators, and I/O image tables. Backed up by a lithium battery to prevent memory loss during power cuts.
  • EEPROM / Flash Memory: Non-volatile backup storage of user programs.

2. Input/Output Modules

Provides galvanic safety and electrical interfacing between delicate $5\text{ V}$ processor chips and rugged $230\text{ V AC} / 24\text{ V DC}$ factory machinery:

  • Input Modules: Use opto-isolators (LED + phototransistor) to convert noisy field voltages into clean logic levels while blocking high-voltage surges.
  • Output Modules:
    • Relay Outputs: Mechanical contacts; switches both AC and DC loads up to $2\text{ A}$; slow switching speed, limited contact lifespan.
    • Transistor Outputs: Solid-state (NPN/PNP); switches DC loads only; ultra-fast switching, practically infinite lifetime.
    • Triac Outputs: Solid-state; switches AC loads only; zero-crossing switching, ideal for AC solenoids.

3. Power Supply Unit

Converts incoming AC mains ($230\text{ V AC}$) into regulated DC voltages ($+5\text{ V}$ for processor logic, $+24\text{ V}$ for field I/O). Includes surge suppression, electromagnetic filtering, and hold-up capacitors that provide $20\text{–}50\text{ ms}$ of backup power during sudden voltage dips so the CPU can execute an orderly shutdown.

4.3 Ladder Logic Fundamentals & Realisation of Logic Gates

💡 In Simple Terms:
  • Series Contacts = AND: Both switch A AND switch B must be closed to complete the electrical path.
  • Parallel Contacts = OR: Either switch A OR switch B can complete the electrical path.
  • Normally-Closed Contact = NOT: Current flows when the input is OFF; opening the input cuts power.

The Concept of Latching (Seal-In Circuit)

💡 In Simple Terms: A start pushbutton only stays pressed as long as your finger is on it. When you let go, it springs back open. A seal-in latch connects an auxiliary contact of the motor itself in parallel with the start button. Once the motor turns ON, its own contact closes and "seals" power to itself—allowing the motor to keep running forever until you press the STOP button!

4.4 PLC Timers and Counters

1. Timers

Internal software instructions replacing mechanical timing relays. A timer has three key words:

  • Preset Value (PRE): The target time count to reach.
  • Accumulated Value (ACC): The elapsed time counted so far (resets to 0 when disabled).
  • Time Base: Duration of each tick ($0.01\text{ s}, 0.1\text{ s}, 1.0\text{ s}$). Total Delay $= \text{PRE} \times \text{Time Base}$.
  • Bits: EN (Timer Enabled), TT (Timer Timing), DN (Done bit—sets TRUE when $\text{ACC} \ge \text{PRE}$).
Timer TypeBehavior When Rung Becomes TRUEBehavior When Rung Goes FALSE
TON (On-Delay)Starts timing. DN bit turns ON after delay.Resets immediately ($\text{ACC} = 0$, $\text{DN} = 0$).
TOF (Off-Delay)DN bit turns ON immediately.Starts timing. DN stays ON for delay duration, then turns OFF.
RTO (Retentive)Starts timing like TON.Retains accumulated value! Only resets via explicit RES instruction.

2. Counters

Counts false-to-true (0 to 1) transitions of an input sensor (e.g., photo-eye detecting passing boxes).

  • CTU (Count-Up): Increments $\text{ACC}$ by 1 on each pulse edge. Sets $\text{DN}$ bit when $\text{ACC} \ge \text{PRE}$.
  • CTD (Count-Down): Decrements $\text{ACC}$ by 1 on each pulse edge.
  • CTUD (Up/Down): Tracks net inventory (e.g., parking garage cars entering vs exiting).
  • RES (Reset Instruction): Counters do NOT reset when input drops. A separate rung with a [RES] instruction resets $\text{ACC} = 0$.

Explain PLC ladder programming / input elements and output elements.

3 marks
Jun 2023 · Q8May 2024 · Q8Apr 2025 · Q8Apr 2026 · Q7

Ladder Programming (LD): A graphical programming language standardised under IEC 61131-3 that mimics electromechanical relay schematic diagrams. It consists of vertical power rails and horizontal rungs evaluated from left to right, top to bottom.

  • Input Elements (Contacts): Instructions that examine memory bits:
    • -| |-- XIC (Examine If Closed): Evaluates TRUE if bit is 1 (normally-open contact).
    • -|/|-- XIO (Examine If Open): Evaluates TRUE if bit is 0 (normally-closed contact).
  • Output Elements (Coils): Instructions that control memory bits:
    • --( )-- OTE (Output Energise): Sets bit to 1 if rung logic is true; 0 if false.
    • --(L)-- / --(U)-- OTL / OTU: Retentive Latch and Unlatch instructions.

Give the significance of timers and counters in a PLC.

3 marks
Jun 2023 · Q7Apr 2026 · Q8

Significance: Replaces fragile, expensive electromechanical timing relays and mechanical revolution counters with flexible, high-precision software blocks.

  1. Timers: Provide programmable delays, sequence timing, and flashing alarms based on internal clock time bases ($0.01\text{ s}, 0.1\text{ s}, 1\text{ s}$). Continually increments accumulator ACC while enabled until preset PRE is reached.
  2. Counters: Count discrete events (products passing photo-sensors, motor rotations). Increments accumulator ACC only on false-to-true rising edges. Eliminates mechanical wear, never loses calibration, and resets instantly via software.

Discuss latching in PLC.

3 marks
Apr 2025 · Q7

Latching is a ladder logic circuit where an output coil keeps itself energised even after the initiating input signal turns OFF. A normally-open contact of the output coil is wired in parallel with the momentary Start pushbutton (seal-in contact), while a normally-closed Stop contact is wired in series. When Start is pressed, the output turns ON, closing its own auxiliary contact to maintain power. Pressing Stop breaks the circuit and unlatches the output.

2. Detailed Explanation of Sub-Components

  1. Central Processing Unit (CPU): Contains the microprocessor that fetches, decodes, and executes ladder instructions. Manages the continuous Scan Cycle (Input read $\to$ Logic solve $\to$ Output update). Includes a quartz clock for internal timing and a hardware watchdog timer that trips the system safely if software hangs.
  2. Memory System:
    • System ROM: Permanent operating system and firmware written by manufacturer.
    • User RAM: Holds user ladder logic, timer/counter presets, and dynamic I/O image tables. Protected by battery backup.
    • Flash EEPROM: Non-volatile backup storage of the program.
  3. Input Interface Module: Connects field input devices ($24\text{ V DC}, 230\text{ V AC}$) to delicate internal $5\text{ V}$ CPU logic. Contains opto-isolators (LED + phototransistor) that provide electrical barrier isolation ($1.5\text{–}3\text{ kV}$) to protect the CPU against field spikes.
  4. Output Interface Module: Transmits CPU decisions to field actuators. Available as dry relay contacts (AC/DC, $2\text{ A}$), high-speed transistors (DC only), or triacs (AC only).
  5. Power Supply Module: Converts noisy AC mains into precision regulated DC voltages ($+5\text{ V}$ logic, $+24\text{ V}$ sensor power). Includes EMI line filters, surge arrestors, and brownout hold-up capacitors.
  6. Programming Device & Communication Interface: PC running engineering software connected via Ethernet, USB, or RS-485 to download, monitor, and debug ladder rungs live.

3. The Interconnecting Buses

  • Address Bus: Unidirectional lines determining which memory byte or I/O slot the CPU is reading/writing.
  • Data Bus: Bidirectional parallel lines transferring instruction words and measurement values between blocks.
  • Control Bus: Timing lines carrying Read/Write strobe signals, system clock, and hardware interrupt lines.

Q. Explain the importance of Power Supply and CPU in a PLC.

6 marks each
Jun 2023 · Q17(b)Jun 2023 · Q18(b)

1. Importance of the Power Supply in a PLC (6 marks)

  1. Regulated Logic Voltages: Generates stable $+5\text{ V}$ and $+3.3\text{ V}$ DC for microprocessors; even a tiny $5\%$ voltage sag would cause digital logic errors or microcomputer resets.
  2. Heavy Industrial Line Filtering: Factory mains are plagued by motor starting surges, harmonic distortion, and welding spikes. The power supply filters these transients before they reach delicate ICs.
  3. Brownout Protection & Hold-Up Time: During momentary power interruptions ($20\text{–}50\text{ ms}$), reservoir capacitors sustain DC output long enough for the CPU to safely store volatile data into retentive memory before shutdown.
  4. Battery Backup Charging: Maintains the lithium backup battery that protects user RAM programs and real-time clock during prolonged factory power outages.
  5. Isolation Barrier: Galvanically isolates hazardous $230\text{ V AC}$ mains from the plant operator and low-voltage digital electronics.

2. Importance of the CPU in a PLC (6 marks)

  1. Master Control & Coordination: Serves as the central brain directing all data transfers across address, data, and control buses.
  2. Program Execution: Solves ladder logic rungs sequentially at microsecond speeds, performing Boolean gating, PID math, counting, and data comparisons.
  3. Deterministic Scan Management: Manages the rigid 3-phase scan cycle (Input Read $\to$ Logic Solve $\to$ Output Write), ensuring deterministic control of fast machinery.
  4. Self-Diagnostics & Safety: Constantly monitors internal memory parity, I/O module health, and bus communication. Resets a hardware watchdog timer each scan cycle; if the program hangs, the watchdog trips and safely turns all outputs OFF.
  5. Communications Hub: Manages data interchange with SCADA networks, remote I/O drops, and operator touchscreens (HMIs).

1. NAND Logic: $Y = \overline{A\cdot B} = \bar A + \bar B$ (De Morgan's Law)

The output is ON for all states except when both inputs A and B are simultaneously ON. In ladder logic, this is realised as two normally-closed (NC) contacts in parallel:

 |--+---|/|---+-------------------------------------( )---|
 |  |  I0.0   |                                      Q0.0
 |  |  (A)    |                                      (NAND Output)
 |  +---|/|---+
        I0.1
        (B)

 Truth Table:
  I0.0 (A)   I0.1 (B)  |  Q0.0 (NAND)
     0          0      |     1   (Both NC contacts closed -> Power flows)
     0          1      |     1   (Contact A closed -> Power flows)
     1          0      |     1   (Contact B closed -> Power flows)
     1          1      |     0   (Both NC contacts open -> Power cut!)

2. XOR (Exclusive-OR) Logic: $Y = A\oplus B = A\cdot\bar B + \bar A\cdot B$

The output is ON if either input is ON, but NOT both. In ladder logic, this is realised by two parallel rungs, each consisting of one NO contact and one NC contact in series:

 |--+---| |--|/|---+--------------------------------( )---|
 |  |  I0.0  I0.1  |                                 Q0.1
 |  |  (A)   (B')  |                                 (XOR Output)
 |  |              |
 |  +---|/|--| |---+
       I0.0  I0.1
       (A')  (B)

 Truth Table:
  I0.0 (A)   I0.1 (B)  |  Q0.1 (XOR)
     0          0      |     0   (Neither branch conducts)
     0          1      |     1   (Bottom branch A'.B conducts)
     1          0      |     1   (Top branch A.B' conducts)
     1          1      |     0   (Both branches broken)

Q. Explain the working of counters in a PLC with an example program and mention applications.

6 – 8 marks
Jun 2023 · Q17(a)May 2024 · Q18(a)Apr 2025 · Q17(b)

1. Operating Principle & Counter Parameters

A PLC software counter monitors an input sensor and increments its Accumulated Value (ACC) each time the input transitions from false to true ($0 \to 1$). Parameters:

  • Preset Value (PRE): The target count.
  • Accumulated Value (ACC): The current count of pulses received.
  • Done Bit (DN): Sets to 1 when $\text{ACC} \ge \text{PRE}$.
  • Reset Instruction (RES): A separate instruction that clears $\text{ACC} = 0$ and $\text{DN} = 0$.

2. Example Program: 10-Bottle Box Packing System

A conveyor carries bottles past a photoelectric sensor (I0.0). When 10 bottles pass, the conveyor stops and a packaging ram energises (Q0.0). Pressing Reset button (I0.1) clears the counter.

 Rung 1: Count each bottle passing photo-sensor I0.0
 |--| |---------------------------------[ CTU C5:0        ]--|
    I0.0 (Photo Sensor)                       Preset: 10
                                              Accum:   0

 Rung 2: When count reaches 10, energise Packaging Ram Q0.0
 |--| |---------------------------------------------------( )--|
    C5:0/DN (Done bit)                                     Q0.0 (Packaging Ram)

 Rung 3: Reset counter via operator button I0.1
 |--| |-------------------------------------------------[ RES C5:0 ]--|
    I0.1 (Reset Pushbutton)

Applications: (1) Batch filling of pills and bottles, (2) Monitoring parking garage capacity (Up/Down counter), (3) Machine maintenance scheduling based on operation cycles, (4) Cut-to-length sheet metal shears.

Q. Explain various timers used in a PLC (TON, TOF, RTO) with timing diagrams.

6 marks
May 2024 · Q17(a)Apr 2025 · Q18(b)Apr 2026 · Q18(b)

1. On-Delay Timer (TON)

Delays turning an output ON. When the rung goes TRUE, the timer starts counting. When $\text{ACC} = \text{PRE}$, the Done bit (DN) sets TRUE. If the rung goes FALSE at any point, the timer immediately resets ($\text{ACC} = 0$).

 Input Rung   ____|---------------------------------|__________
 TON Output   ______________________|---------------|__________
                      |<-- Delay t -->|

2. Off-Delay Timer (TOF)

Delays turning an output OFF. When the input rung goes TRUE, the output turns ON immediately. When the input rung goes FALSE, the timer begins timing. The output remains ON during the delay, turning OFF only when time expires.

 Input Rung   ____|------------------|_________________________
 TOF Output   ____|---------------------------------|__________
                                     |<-- Delay t -->|

Application: Cooling fan running for 60 seconds after a furnace or motor has been switched off.

3. Retentive On-Delay Timer (RTO)

Functions identically to a TON, with one vital difference: if input power is lost or the rung goes FALSE midway, the timer remembers its accumulated time! When power returns, it resumes timing from where it left off. It can only be reset by an explicit [RES] instruction.

Application: Tracking cumulative motor running hours across shifts for scheduled bearing lubrication.

Q. Devise a ladder program to switch on a pump for 100 s; it is then switched off and a heater switched on for 50 s. Then the heater is switched off, and another pump is used to empty the water.

Step-by-Step Circuit Operation

  1. Start: Pressing button I0.0 energises master relay M0.0, which seals itself in through its parallel contact (Rung 1).
  2. Step 1 (Pump 1 ON): Because M0.0 is TRUE and T4:1/DN is FALSE, Pump 1 (Q0.0) starts filling water (Rung 2). Concurrently, timer T4:1 starts timing 100 seconds (Rung 3).
  3. Step 2 (Heater ON): At $t = 100\text{ s}$, timer T4:1 finishes and sets bit T4:1/DN TRUE. This opens Rung 2 (stopping Pump 1) and closes Rung 4 (turning ON the Heater Q0.1). Concurrently, timer T4:2 starts timing 50 seconds (Rung 5).
  4. Step 3 (Pump 2 ON): At $t = 150\text{ s}$, timer T4:2 finishes and sets bit T4:2/DN TRUE. This opens Rung 4 (switching OFF the Heater) and closes Rung 6 (turning ON Pump 2 to drain the tank).
  5. Stop: Pressing Stop button I0.1 de-energises M0.0, immediately shutting down all timers and pumps.
